### 스크린샷 촬영 (본인)
APK를 폰에 설치한 뒤 기기에서 직접 캡처하는 게 가장 좋다 — 실제 기기 화면이라 심사에서도 자연스럽고, 에뮬레이터보다 결과가 낫다.

찍으면 좋은 4장:
1. 도안 편집 화면 — 기호가 격자에 배치된 상태
2. 기호 팔레트를 연 화면 — 기호 종류가 많다는 게 보이도록
3. 뜨면서 진행 체크 화면 — 차별점
4. 서술도안 결과 화면 — 차별점

## 데이터 보안(Data safety) 설문 답안

코드 확인 결과에 근거한 답안이다 (분석·추적 도구 0개, 외부 서버 통신 없음, 권한은 INTERNET 하나).

- 앱이 사용자 데이터를 수집하거나 공유합니까? → **아니요**
- 데이터가 전송 중에 암호화됩니까? → 해당 없음(전송하는 데이터 없음)
- 사용자가 데이터 삭제를 요청할 수 있습니까? → 해당 없음(앱 삭제로 전부 제거됨)

★ 나중에 클라우드 저장·계정 기능을 붙이면 이 답안을 반드시 갱신해야 한다.

## 출시 순서

1. `privacy.html` 푸시 → URL 살아있는지 확인
2. 키스토어 생성 (`docs/ANDROID-BUILD.md` 2번)
3. 릴리스 AAB 빌드 → `android/app/build/outputs/bundle/release/app-release.aab`
4. 플레이 콘솔에서 앱 만들기 → 위 등록물 입력
5. **비공개 테스트** 트랙에 AAB 업로드 → 테스터 12명 초대
6. 12명이 **실제 설치** + **14일 연속** 경과
7. 프로덕션 액세스 신청 (검토 약 7일)
